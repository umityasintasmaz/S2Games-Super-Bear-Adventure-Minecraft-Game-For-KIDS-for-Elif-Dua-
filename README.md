# S2Games: Super Bear Adventure & Minecraft Game For KIDS (for Elif Dua)

🐻 **Super Bear Adventure** ve ⛏️ **Minecraft** evrenlerini bir araya getiren, **Elif Dua** için özel olarak tasarlanmış çocuk dostu 3D voxel sandbox ve macera oyunu.

---

## 🌟 Oyun Hakkında (About the Game)

**S2Games: Super Bear Adventure & Minecraft Game For KIDS (for Elif Dua)**, küçük çocukların güvenle, eğlenerek oynayabileceği, şiddet içermeyen, renkli ve Türkçe sesli yönlendirmelere sahip 3D bir keşif ve inşa oyunudur.

Kahramanımız **Super Bear**, büyük ayı köşkünden yola çıkarak ormandaki kayıp küçük ayı kardeşlerini kurtarır, bal çömleklerini toplar, sınırsız bloklarla hayalindeki dünyayı inşa eder ve dağın zirvesindeki sihirli portaldan geçerek Kutsal Tacı kazanır.

---

## 🎮 Temel Özellikler (Features)

- 🎙️ **Türkçe Sesli Yönlendirme (Voice Guidance):**
  - Seçilen her bloğu (Altın, Kum, Bakır, vb.) Türkçe olarak tanıtır.
  - Görevleri ve hedefleri sesli okur.
  - Küçük ayılara veya portala yaklaşıldığında Elif Dua'ya sesli ipuçları verir.
- 🧱 **Sınırsız Blok İnşaatı:**
  - 👑 **Altın Blok:** Parıltılı kraliyet yapıları için.
  - 🏖️ **Kum Bloğu:** Sahil ve plaj tasarımları için.
  - 🟫 **Bakır Bloğu:** Sağlam ve sıcak yapılar için.
  - 💎 **Elmas Blok, 🍯 Zıplayan Bal Bloğu, 🌱 Çimen, 🧱 Tuğla, 🪵 Meşe Odunu, 🔮 Mor Kristal**.
- 🐻 **Ayı Kurtarma Görevi:**
  - Köşkteki yatakta ve ormanda bekleyen 4 sevimli küçük ayıyı kurtarma macerası.
- 🌀 **Çift Boyutlu Dünya (Overworld & Portal World):**
  - Dağın zirvesindeki gizemli portaldan geçerek uçan adalara ışınlanma.
- 👑 **Kutsal Taç & Kutlama:**
  - Zirvedeki kutsal tacı alarak oyunu tamamlama ve havai fişek konfetisi kutlaması.
- 📱 **Çocuk ve Tablet Dostu Kontroller:**
  - İster klavye ve fareyle, ister ekrandaki dokunmatik yön tuşlarıyla kolay kontrol.

---

## 🕹️ Kontroller (Controls)

| Eylem | Klavye / Fare | Dokunmatik / Ekran |
| :--- | :--- | :--- |
| **Hareket** | `⬆️ ⬇️ ⬅️ ➡️` veya `W A S D` | Sağ alttaki Yön Butonları |
| **Zıpla** | `Boşluk (Space)` veya Çift `⬆️` | Ekrandaki 🦘 Zıpla Butonu |
| **Blok Koy (Place)** | **🖱️ Sol Tık** veya `E` / `B` | Ekrandaki 🧱 Koy Butonu |
| **Blok Kır (Mine)** | **🖱️ Sağ Tık** veya `F` / `Enter` | Ekrandaki ⛏️ Kır Butonu |
| **Kamera Açısı** | `C` tuşu (1. / 3. Şahıs) | Ekrandaki 🎥 Kamera Butonu |
| **Element / Slot** | `1` - `9` tuşları veya fare tekerleği | Alttaki Hızlı Seçim Çubuğu |

---

## 🛠️ Teknolojiler (Tech Stack)

- **Engine:** Three.js (3D Voxel rendering, lighting, particles & procedural physics)
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Audio & Speech:** Web Audio API synth sound engine & Web Speech Synthesis API
- **Icons & FX:** Lucide React & Canvas Confetti
